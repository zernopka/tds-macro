# TDS Macro

Макрос для **Tower Defense Simulator** (Roblox): записываешь свою стратегию один раз — он играет её сам и фармит по кругу, хоть всю ночь.

> **Бета.** Нашёл баг — открой [Issue](../../issues) и приложи файл из папки `logs`.

## Что умеет
- **Запись стратегии** — играешь матч сам, макрос записывает постановку, апгрейды, продажу, абилки, скипы волн.
- **Фарм по кругу** — заходит на твой VIP-сервер, выбирает карту и режим, играет запись, перезаходит.
- **Timescale x1.5 / x2** — сам тратит тикет перед стартом матча; запись хранит игровое время, поэтому стратегия, записанная на x1, ровно играется на x2.
- **Автонадевание башен** из инвентаря перед матчем.
- **Окно с настройками** на русском и английском, гайд по настройкам Roblox внутри.
- **F2** — стоп в любой момент (ещё раз — экстренный стоп).

## Установка
1. Скачай zip и **распакуй** (правой кнопкой → «Извлечь всё»). Из архива не запускается.
2. Нужен **Microsoft Edge WebView2 Runtime** (на Windows 11 уже есть). Если его нет — макрос сам скажет и даст ссылку.
3. Запусти `TDSMacro.exe`. Windows попросит права администратора — они нужны, чтобы нажимать клавиши и мышь в Roblox.
4. **Обязательно открой «Гайд»** в меню слева и прочитай его целиком. Выставь в Roblox всё как там: **чувствительность камеры (Camera Sensitivity) 0.2**, бинды, геймплей, графика, размер интерфейса. Без этого макрос будет промахиваться.
5. Roblox — на весь экран, 1920×1080.
6. **«Настройки» → «Общее»** → вставь ссылку на свой VIP-сервер.

## Как записать стратегию
1. Зайди в игру (на свой VIP-сервер).
2. Выбери режим, потом карту — как обычно.
3. Когда оказался на карте — **не трогай камеру** (не крути, не приближай).
4. Нажми **F6** — запись пошла. Играй матч как обычно: ставь башни, качай, жми абилки клавишами.
5. Нажми **F6** ещё раз — запись сохранится и появится в «Записи».
6. У записи нажми **«▶ Фармить»** — макрос будет играть её по кругу.

**Горячие клавиши:** F2 — стоп, F4 — автоскип, F6 — запись.

## Частые вопросы
**«Windows защитил ваш компьютер»** — «Подробнее» → «Выполнить в любом случае». У программы нет платной цифровой подписи.

**Нажал — ничего не происходит** — проверь, что архив распакован, и что ты нажал «Да» в окне прав администратора. Ошибки пишутся в `logs\gui_exe.log`.
